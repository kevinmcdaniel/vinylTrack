Standard action button.

```jsx
<Button variant="primary" icon="＋">Call</Button>
<Button variant="success">Activate</Button>
<Button variant="secondary">Cancel</Button>
```

Variants: `primary` (accent fill — the one main action), `secondary` (outline), `ghost` (accent text, toolbar), `success` (save/activate green). Sizes `sm`/`md`/`lg`. Hover darkens automatically; `disabled` dims to 45%.
