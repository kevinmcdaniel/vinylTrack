Compact 1–5 difficulty meter — the signature SquareTrack signal, used on call rows, the editor choreo column, and teaching-order lists.

```jsx
<DifficultyPips level={4} />
```

`level` lights that many pips along the shared green(easy)→red(hard) ramp. `max` defaults to 5; `width`/`height` size the bars (use a shorter height inline in dense lists). Identical in both themes — never recolor it.
