Marks the activator (who does the call) — Heads, Sides, Boys, Centers, Leads.

```jsx
<DesignatorPill text="Heads" tone="editor" />
<DesignatorPill text="Boys" tone="inline" />
```

`editor` tone is the terracotta mono pill used in the spoken column. `inline` tone is the muted prefix that sits back inside a bright live call line. Returns null for empty text.
