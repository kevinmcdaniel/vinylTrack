# vinylTrack

Family record/album/MP3 collection tracker — multiple named collections (Vinyl, Square Dance Calls, General MP3s, …), shared across family members and devices.

See [CLAUDE.md](./CLAUDE.md) for architecture and dev commands, and the [GitHub issues](https://github.com/kevinmcdaniel/vinylTrack/issues) for the full design/plan.

## Quick start

```bash
cp .env.example .env   # fill in secrets
docker compose up
```

- FE: http://localhost:5201
- BE: http://localhost:5202
- Prisma Studio: http://localhost:5203
