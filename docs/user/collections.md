# Collections

A collection is one set of music kept together, like *Vinyl* or *Square Dance Calls*. Each one has its own albums, copies and storage places.

## Which ones you see

You only see collections that are yours or that someone shared with you. If one you expected is missing, ask the person it belongs to or the family admin.

## Switching

On a collection page, the box at the top names the collection you're in and how many albums it has. That counts albums, not copies: one album can have several copies. Pick another collection from the box to switch.

## Physical and digital

A collection is either **physical** (records, CDs, tapes) or **digital** (music files). Physical collections show each copy's condition and where and when it was bought. Digital ones leave that out.

## Starting a collection

Tap **New collection** at the top. Give it a name, pick physical or digital, add notes if you like, and tap **Create collection**.
